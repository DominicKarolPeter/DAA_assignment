#DAA project
The project is on a simple game from Simon Thatam named Flood . The game is  about filling a grid layout from top left and filling the entire grid with one color in the least possible moves possible .
Just pull the folder locally and run the tkinter py file , everything else is understandable by a cild.
Choose the grid size and number of moves and start playing . 
The game is done mostly by ourself with AI help in only debugging.
